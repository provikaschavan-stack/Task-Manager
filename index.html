Console Based Task Manager

This is a simple console-based task manager written in Python. It lets you add, list, complete, and delete tasks, which are stored in a tasks.json file for persistence.

Project Structure

Consol Based Tasks Manager/
    main.py
    models.py
    storage.py
    tasks.json
    index.html

How to Run

  1. Make sure Python 3 is installed.
  2. Open a terminal in the project folder.
  3. Run: python main.py

You will see a menu like this:

=== Console Task Manager ===
1. List tasks
2. Add task
3. Mark task as completed
4. Delete task
5. Exit

Example Usage

Add a new task:

Choose an option: 2
Title: Buy groceries
Description (optional): Milk, eggs, bread
Due date (YYYY-MM-DD, optional): 2026-07-25
Task [1] added.

List tasks:

Choose an option: 1

Tasks:
[1] ✗ Buy groceries (Created: 2026-07-24T23:20:15, Due: 2026-07-25)
    Milk, eggs, bread

About

Built with core Python only, this project is ideal for learning:

  • Classes and dataclasses
  • File handling (JSON storage)
  • Menu-driven console applications
